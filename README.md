## 🚀 Proyectos destacados

### Proyecto 1: Análisis de comportamiento de clientes — Instacart

Análisis exploratorio de datos de pedidos para identificar patrones de compra y comportamiento de los clientes.

**Trabajé con:**
- Limpieza de datos
- Valores ausentes y duplicados
- `groupby`
- `merge`
- Proporciones y frecuencias
- Visualización de distribuciones
- Análisis de productos más comprados y reordenados

**Herramientas:** Python, Pandas, Matplotlib

---

### Proyecto 2: Análisis de clientes de telecomunicaciones

Análisis del comportamiento de usuarios de diferentes planes de telefonía para estudiar su consumo y los ingresos generados.

**Trabajé con:**
- Llamadas, mensajes y consumo de internet
- Agregación de datos por usuario y mes
- Comparación entre planes
- Medias y varianzas
- Distribuciones de probabilidad
- Aproximación normal
- Pruebas de hipótesis
- Análisis de ingresos mensuales

**Herramientas:** Python, Pandas, NumPy, Matplotlib, SciPy
